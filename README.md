# Tesla Navi

2021~2022년식 Tesla Model 3 / Model Y용 개인 Android 앱.

현재 버전 **0.4.6**은 차량 접근 시 자동 연결, 주행 시작 후 카카오내비 단속카메라 화면·음성 안내를 포함합니다. 고속도로 500 m·일반도로 300 m에서 카메라 존재를 알리고, 접근 구간에서 단속지점 제한속도보다 5 km/h 이상 빠르면 과속을 경고합니다. 제공된 APK에는 사용자가 지정한 네이티브 앱 키가 기본으로 포함됩니다. 실차 연결, 접근 감지, 카카오 서버 인증 및 실제 주행 안내는 사용자 차량에서 확인해야 합니다.

0.4.6 설정 진입: 화면 상단 제목 아래에 민트색 전체 너비의 안내 설정 버튼과 조절 아이콘을 배치했습니다.

0.4.5 안내 복구: 카카오 초기화·안내 시작 실패 시 5~30초 간격으로 재시도하며 주차·연결 종료 시 재시도를 취소합니다. 접근 구간의 전체 카메라에서 과속 여부를 확인하고 경고 대상 카메라의 제한속도를 화면에도 표시합니다. TTS 초기화 실패와 경고음을 분리했습니다. 5분 주차 시 강제 연결 해제를 제거하여 재출발을 감지합니다. 대신 차량 근처에서 오래 대기하면 연결·배터리 사용이 늘 수 있습니다. 경고음은 부드러운 시작·끝과 배음이 있는 48 kHz 종소리로 변경했습니다. 음원 출처 후보와 구현 설명은 [AUDIO.md](AUDIO.md)에 있습니다.

0.4.4 소리 테스트: 안내 설정에서 카메라 음성과 과속 경고음을 각각 들어볼 수 있습니다. 실제 주행과 같은 음성·경고음 출력을 사용하며 차량 연결이 필요하지 않습니다. 설정한 앱 음량이 적용되고, 경고음은 약 6초 뒤 종료합니다. 테스트 중지·설정창 닫기·앱을 다른 화면으로 전환하면 재생을 중단합니다. 실제 주행 안내 중에는 테스트 버튼을 비활성화합니다. 휴대폰 미디어 음량이 0이면 테스트 소리도 들리지 않습니다.

0.4.3 음성 중단 처리: Android TTS의 중단 콜백에서도 음성 재생 상태를 해제합니다. 중단 후 다음 과속 음성과 반복 경고음을 재생할 수 있는지, 이전 음성의 늦은 콜백이 새 음성을 방해하지 않는지 회귀 테스트를 추가했습니다. 이 수정만으로 과거 주행 중 경고가 없었던 원인을 확정할 수는 없습니다.

0.4.2 다중 차량 자동 연결: 키 등록·인증을 완료한 등록 차량 전체를 검색하고 먼저 감지된 연결 가능한 근접 차량에 연결합니다. 수동 선택과 무관하며 연결되는 차량을 화면에서 자동 선택합니다. 한 차량의 연결·인증 또는 기존 연결 중에는 다른 차량으로 전환하지 않습니다. 차량별 재시도를 분리했고 미등록·미인증 차량은 연결하지 않습니다.

0.4.1 안내 설정:
- 화면 상단 **안내 설정**에서 안내 음량 0~100%, 고속도로 100~2,000 m, 일반도로 100~1,000 m를 조절합니다. 거리는 100 m 간격입니다. 슬라이더 조작 완료 시 자동 저장되며 기본값 복원도 지원합니다.
- 기본값은 음량 100%, 고속도로 500 m, 일반도로 300 m입니다. 음량은 휴대폰 미디어 음량에 대한 앱 출력 비율이며 TTS와 띵똥 경고음에 함께 적용됩니다. 0.4.0의 미디어 볼륨 자동 30% 증폭·복원 방식은 제거했습니다. 미디어 음량이 0이면 앱 음량이 100%여도 들리지 않습니다. 새 음량은 다음 음성부터 적용되고, 재생 중 경고음은 즉시 반영됩니다. 0%는 현재 출력도 중지합니다.
- 설정한 거리는 카메라 존재 안내와 과속 경고의 접근 구간에 함께 적용됩니다. 도로 종류 미확인 시 고속도로 설정값을 사용합니다. 주행 중 변경해도 경로를 재탐색하지 않고 다음 위치 갱신에서 반영하며 이미 알린 카메라는 중복 안내하지 않습니다. SDK가 카메라를 늦게 제공하면 설정 거리보다 늦게 안내될 수 있습니다.

0.4.0 변경:
- 고속도로 500 m·일반도로 300 m 알림구간 내 제한속도 +5 km/h부터 “제한속도 XX킬로미터 초과입니다”를 한 번 말하고, 과속 상태가 해제될 때까지 2초 간격으로 2음 경고음을 냅니다. 감속·구간 이탈·GPS 만료·음소거·주차·연결 종료 시 경고음을 멈춥니다.
- 거리 음성은 100 m 단위 반올림(423 → 400, 450 → 500). 50 m 미만은 “잠시 후”. 실제 표시 거리와 판정 기준은 유지합니다.
- 주행 시작 시 “주행시작”을 한 번 안내합니다. 목적지 변경·일시 재연결에서는 반복하지 않고 P단에서 다음 주행을 준비합니다.
- 안내 중 미디어 볼륨을 현재 값의 1.3배로 높입니다(단계 올림, 시스템 최댓값 제한). 출력 종료 시 복원하되 사용자가 중간에 변경한 값은 유지합니다. 미디어 무음 0은 유지합니다.
- 자동 연결 대기 서비스가 알림을 소유하며 차량 연결 서비스는 추가 알림을 게시하지 않습니다. 자동 연결 없이 수동 연결만 할 때는 차량 연결 알림 하나를 사용합니다. 알림 전용 투명 흰색 아이콘으로 변경했습니다.
- 접근 시에만 알림을 띄우는 기능은 적용하지 않았습니다. 현재 포그라운드 서비스를 종료하면 화면이 꺼진 상태의 접근 감지 및 서비스 재시작이 제한될 수 있습니다. 대기에는 무음 알림 하나를 유지합니다.
- 2026-10-23 사용자 휴대폰 로그에서 단발 8초 응답 누락마다 BLE 전체 연결을 다시 만드는 것을 확인했습니다. 같은 BLE 연결에서 3회 연속 누락 전까지 재조회합니다. 단절·기타 오류 및 연속 누락 시에는 기존 재연결을 사용합니다. 전송 시작 실패에는 Android 반환 코드를 기록합니다. 실제 응답 누락 원인 및 실주행 개선 효과는 추가 검증이 필요합니다.

0.3.4에서는 연결 단계·오류와 앱 버전을 날짜·시간·시간대와 함께 앱 내부에 저장합니다. 최근 160개 기록은 다음 연결, 앱 종료·재실행 후에도 유지됩니다. 저장 위치는 앱 전용 `shared_prefs/connection-history.xml`이며, 앱에서 **연결 기록 보기 → 연결 기록 복사**로 확인할 수 있습니다. 기존 0.3.3의 소실된 Logcat 기록은 복구할 수 없습니다. 2026-10-22 연결된 휴대폰에서 프로세스 종료·재실행 후 기존 기록 유지와 새 기록 추가를 확인했습니다. 차량 연결 실패 원인 자체는 아직 미확정입니다.

0.3.3에서는 BLE 신호를 일부 제외할 수 있는 `neverForLocation` 선언을 제거하고 정확한 위치 권한·위치 기능을 검색 전에 확인합니다. VIN 이름 필터로 10초 검색 후 미발견 시 20초 보조 검색으로 전환합니다. 보조 검색 시 휴대폰 화면을 켜 두어야 하며, 여전히 VIN에서 계산한 이름과 정확히 일치하는 연결 가능 신호에만 연결합니다. 실패 시 신호 미수신·일반 신호만 수신·다른 Tesla 형식 신호 수신·대상 차량 연결 불가를 구분합니다. 자동 접근 대기는 기존 저전력 필터 검색을 유지합니다. 실차 검색 실패 원인은 재현 로그 확인 전까지 미확정입니다.

0.3.2에서는 키 등록 중 수신하는 VCSEC 거절 응답의 사유·코드를 표시하며, BLE 검색·연결·서비스 검색·전송 설정의 시간 초과를 구분합니다. 등록 성공은 기존과 같이 서명이 검증된 차량 인증으로만 판정합니다. 차량 등록 실패 시 **연결 기록 보기 → 연결 기록 복사**로 앱 버전, 기기 정보, 단계와 오류를 복사할 수 있습니다. 복사 항목에는 VIN·앱 개인키를 포함하지 않습니다. 이 변경은 진단 보완이며, 보고된 실차 등록 실패 원인은 오류 기록 확보 전까지 미확정입니다.

## 설치와 사용

1. `app/build/outputs/apk/debug/app-debug.apk`를 휴대폰에 설치합니다. Android 8.0 이상 및 Bluetooth LE가 필요합니다.
2. 앱의 **차량 등록**에서 Model 3 / Model Y를 선택하고 VIN 17자리를 입력합니다.
3. 차량 가까이에서 화면을 켜고 **처음 연결하나요? 앱 키 등록**을 누릅니다.
4. 차량의 센터 콘솔 카드 리더에 키 카드를 대고 차량 화면의 등록 안내에 따라 승인합니다. 최대 90초 동안 앱에서 등록 상태를 확인합니다.
5. 등록 후 차량 인증이 성공하면 목적지를 표시합니다. 이후에는 **차량 연결**을 누릅니다.
6. 차량 내비게이션에서 목적지를 설정·변경·취소하면서 앱 화면에 반영되는지 확인합니다. 정상 연결 중 5초마다 조회하며 응답 지연으로 더 늦어질 수 있습니다.
7. **연결 종료** 또는 알림의 종료 버튼으로 세션을 끝냅니다. 연결 중에는 다른 차량으로 전환할 수 없습니다.

제공된 APK는 카카오 키 입력 없이 차량 연결을 시작할 수 있습니다. 정확한 위치 권한을 허용하고, 카카오 개발 앱에 패키지명·키 해시가 등록되어 있는지 확인합니다. 앱 내 카카오 연결 설정은 제거했으며, 업데이트 시 이전 키 입력·비활성화 선택도 정리하고 기본 키를 사용합니다. 자세한 절차는 [KAKAO_SETUP.md](KAKAO_SETUP.md)에 있습니다.

자동 사용은 차량 키 등록·인증을 한 번 마친 뒤 **차량 접근 시 자동 연결**을 켭니다. 근처 기기·정확한 위치·알림 및 위치 **항상 허용** 권한이 필요합니다. 인증을 마친 등록 차량 중 먼저 감지된 차량에 연결해 대기하고, 차량 속도가 3 km/h 이상이면 안내를 시작합니다. 신호 대기에서는 유지하고 P단에서는 중지합니다. 자동 연결 대기에는 지속 알림이 표시되며, 수동 연결에서도 같은 주행 시작 조건을 사용합니다. 자세한 자동 연결 동작은 [AUTO_CONNECT.md](AUTO_CONNECT.md)에 있습니다.

USB 연결 시 설치:

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

앱은 차량 정보를 조회하는 `ROLE_VEHICLE_MONITOR` 키를 요청합니다. 키 등록 요청을 보낸 사실만으로 등록 성공을 표시하지 않으며, 차량 인포테인먼트와 인증을 마쳐야 등록을 확인합니다.

## 구현 내용

- Model 3 / Model Y별 VIN 등록·선택과 설정 저장.
- 인증에 성공한 선택 차량의 BLE 접근 감지, 저전력 스캔 대기 서비스와 부팅·업데이트 후 복원.
- 차량 속도 3 km/h 이상에서 안내 시작, 신호 대기 유지, P단에서는 안내만 중지하고 차량 연결은 유지하여 장시간 대기 후 재출발을 감지.
- VIN으로 계산한 Tesla BLE 광고명 검색, GATT 서비스 연결 및 indication/notification 구독.
- MTU 기반 메시지 분할·재조립과 전송 직렬화.
- P-256 ECDH, Tesla KDF, 세션 HMAC 검증, AES-GCM 요청/응답 인증.
- 요청 UUID·발신 도메인·수신 주소로 응답을 구분하고 이전 요청 응답을 무시.
- 목적지 이름·좌표, 남은 시간과 거리 조회. 목적지 취소 시 이전 정보를 제거.
- 카카오내비 SDK를 실제 의존성으로 포함하고 목적지 좌표로 카카오 경로를 탐색.
- 목적지 미설정·취소·경로 탐색 실패 시 안전운행 모드로 전환.
- 도로 매칭 안내 목록에서 과속 관련 카메라만 표시하고 한국어 TTS로 거리·제한속도 사전 안내.
- SDK 도로 종류에 따라 기본 고속도로 500 m·일반도로 300 m 안내(설정 가능). 카메라 접근 구간에서 단속지점 제한속도 +5 km/h부터 과속 음성을 한 번 안내하고, 과속이 지속되면 2초 간격으로 경고음을 반복합니다.
- 위치 만료·경로 이탈·목적지 변경 시 카메라 표시와 음성 초기화, 이전 비동기 응답 무시.
- 화면이 꺼져도 연결을 유지하는 `connectedDevice` 포그라운드 서비스. 카카오 안내 사용 시 `location` 유형을 함께 사용.
- 사용자가 시작한 연결 세션 동안 제한 시간으로 갱신하는 CPU wake lock. 세션 종료 시 해제.
- 연결이 끊기면 목적지를 비우고 최대 3회 재연결. 재접속 시 새 인증 세션 구성.
- 차량별 키 쌍을 Android Keystore의 AES-GCM 키로 암호화해 앱 전용 no-backup 저장소에 보관. Android 8 호환을 위해 ECDH 시 키를 앱 메모리에서 사용.
- 앱 자체 로그에 개인키·카카오 앱 키·차량 응답 본문·이동 경로를 기록하지 않음. UI 연결 기록은 메모리에서만 유지. SDK는 지도·경로 처리에 필요한 데이터를 자체 관리.

## 빌드

JDK 17과 Android SDK Platform 34 / Build Tools 34.0.0을 사용합니다. Android Studio에서 프로젝트를 열면 SDK 경로를 설정할 수 있습니다. 또는 무시되는 `local.properties`에 로컬 경로를 지정합니다.

```properties
sdk.dir=C:/Users/YOUR_NAME/AppData/Local/Android/Sdk
```

## 검증 범위

`protocol` 테스트는 Tesla 공식 문서의 고정 암호화 예제와 ECDH의 0 패딩 벡터, BLE 분할·만료, 키 등록 권한, 암호화된 목적지 조회·변경·취소, 서명/암호문 변조 및 이전 응답 혼입을 검증합니다.

앱 JVM 테스트는 Robolectric에서 첫 화면, 차량 등록, 잘못된 VIN 처리와 차량 선택 저장을 확인합니다. 이는 실제 Android Bluetooth 스택이나 Keystore 하드웨어 테스트를 대체하지 않습니다.

카메라 테스트는 목적지 변경·취소, 차량 전환, 이전 경로 응답, 동일 경로의 반복 탐색 방지, GPS 만료, 안내 중복 억제, 음소거, 음성 엔진/오디오 포커스 오류와 SDK 카메라 분류를 확인합니다. 기본 키가 포함되어 있다는 사실은 SDK 서버 인증 성공으로 표시하지 않습니다.

키 기본값은 Git에서 제외된 `local.properties`의 `kakao.nativeAppKey`를 빌드 시 읽어 APK에 포함합니다. 해당 값을 생략한 빌드는 카메라 안내가 비활성화됩니다. 키 변경은 개발 컴퓨터에서 수정 후 다시 빌드합니다. 현재 SDK 연동에는 REST API 키를 사용하지 않습니다.

2026-10-24 기준 앱 테스트 85개가 통과했습니다. 소리 테스트의 음량 적용·자동 종료·전환·취소·0% 안내·음성 엔진 오류 처리 검증을 포함합니다. 음성 중단 후 안내·경고음 재개와 이전 콜백의 새 음성 간섭 방지 검증을 포함합니다. 다중 차량 후보 검색·미인증 제외·동시 연결 차단·차량별 재시도와 장시간 주차 후 재출발·선택과 무관한 자동 연결 검증을 포함합니다. 설정 저장·복원, 조절값 경계, 주행 중 거리 변경, 설정 화면 조작 및 앱 음량 적용을 포함합니다. 반올림·과속 경고음 중단·주행 시작 중복 방지·음량 복원 검증을 포함합니다. 실패 기록 재로딩·개수 제한·VIN 마스킹·손상된 기록 복구를 포함합니다. 프로토콜 테스트 17개도 통과했습니다. 고속도로/일반도로 경계 거리, +5 km/h 경계, 미확인·가변 제한속도 제외, 과속 경고 간격과 음성 재시도, 키 등록 거절·기존 키·잘못된 수신 주소·서명 검증도 포함합니다. Android Lint는 오류 0개이며 SDK/라이브러리 버전 등에 대한 경고 9개가 남아 있습니다.

실차에서 확인할 항목:

- Model 3와 Model Y 각각의 차량 소프트웨어 버전과 조회 권한 지원.
- 실제 키 카드 등록과 인포테인먼트 동기화, 목적지 필드의 제공 여부.
- 화면 잠금 상태 장시간 연결, Bluetooth 재접속 및 휴대폰 절전 정책.
- 본인 카카오 앱 키의 SDK 인증, 실제 GPS·카메라 데이터 수신, 카카오/테슬라 경로 차이와 TTS 음성 출력.

키 등록 후 조회 권한 오류가 나면 연결 기록의 코드와 차량 소프트웨어 버전을 확인합니다. 앱 데이터 삭제·재설치는 새 키를 만들기 때문에 차량에서 이전 앱 키를 정리하고 다시 등록해야 합니다.
